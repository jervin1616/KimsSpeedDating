# Security

If you find a security problem in Kim's Speed Dating, please tell the host privately (direct message in the community Discord server). Please do not post it publicly until it is fixed.

Tell us what you saw, where, and how to repeat it. Use only your own account and data when testing. Do not read or change other people's information, send large amounts of traffic, or interrupt a live stream.

Never put keys, passwords or the access list in this repository. They are stored as protected Cloudflare secrets. See DEPLOY.md.

The public versions of the policies live in `public/privacy.html`, `public/terms.html` and `public/security.html`.
